JavaScript Flappy Bird Game

I made this game with the help of a tutorial from W3 Schools! I made a couple changes by adding a background image, changing the color of the game piece, changing the color of the obstacles, and changing the color of the score keeper. Use the "accelerate" button to propel yourself upward!
